# Boob Game

A small browser-based countdown game built with HTML, CSS, and JavaScript.

## Run locally

Open `Mini project/Boob Project/page.html` in a browser, or serve the project with any local static web server.

## How to play

Type `defuse` in the input and press Enter before the 10-second countdown reaches zero.

## Project files

- `Mini project/Boob Project/page.html` - game markup
- `Mini project/Boob Project/page.css` - game styles
- `Mini project/Boob Project/page.js` - countdown and defuse logic
